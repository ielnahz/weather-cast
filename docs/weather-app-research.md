# 市面天气应用/网站调研

> 调研时间：2026-11-09
> 目的：分析主流天气产品的功能特点和设计风格，为本项目的产品设计和交互方案提供参考

## 一、调研总览

| 产品 | 类型 | 特色 | 设计风格 | 参考价值 |
|------|------|------|---------|---------|
| Windy | 网站/APP | 动画地图，多模型对比 | ⭐ 视觉标杆 | 地图可视化 |
| Ventusky | 网站/APP | 3D 地球，实时摄像头 | ⭐ 沉浸式 | 3D 可视化 |
| AccuWeather | 网站/APP | MinuteCast 分钟级降雨 | 数据精准 | 短期预报精度 |
| The Weather Channel | 网站/APP | 雷达动画，生活指数 | 大众化，动画丰富 | UI 动效参考 |
| Weather Underground | 网站/APP | 25万+ 个人气象站 | 社区驱动 | 数据来源多样性 |
| WeatherSpark | 网站 | 气候图表，历史对比 | 极简数据可视化 | 图表设计 |

## 二、重点产品分析

### 1. Windy（ windy.com）— 视觉标杆

**亮点**:
- 流体动画地图展示风向、降水、温度等 40+ 气象参数
- 支持切换不同预测模型（ECMWF、GFS、ICON）对比
- 社区插件生态（航空、航海、无人机）
- 摄像头集成

**可借鉴**:
- 动画过渡效果（天气切换时的平滑过渡）
- 多数据层切换的交互方式
- 地图作为信息载体的思路

---

### 2. Ventusky — 沉浸式设计

**亮点**:
- 3D 地球视图，可视化全球天气模式
- 1000+ 实时摄像头集成
- 自定义图层（CAPE、露点等专业数据）
- 离线模式

**可借鉴**:
- 3D 可视化思路（本项目体量可能用不上，但设计理念可参考）
- 图层切换的 UI 模式

---

### 3. AccuWeather — 数据精准

**亮点**:
- MinuteCast：分钟级降雨预测（功能上无竞品能比）
- RealFeel 温度：考虑湿度、风速、云量的体感温度
- 270万地点覆盖
- 健康指数：花粉、流感风险、紫外线
- 15天展望

**可借鉴**:
- "体感温度"概念——可以在项目中展示
- 生活指数的设计思路（穿衣、紫外线等）

---

### 4. The Weather Channel — 交互丰富

**亮点**:
- 可缩放雷达图层
- 实时风暴追踪 + 路径预测
- 健康预报（花粉、空气质量、流感）
- 视频内容
- 高质量动画效果

**可借鉴**:
- 天气状态的动画切换（晴天/雨天/雪天的背景过渡）
- 信息层次组织

---

### 5. Weather Underground — 社区驱动

**亮点**:
- 25万+ 个人气象站众包数据
- Wundermap：带摄像头的交互式雷达
- AI 驱动的活动定制预报
- 活跃社区论坛

**可借鉴**:
- 数据来源多样性的设计考量

---

### 6. WeatherSpark — 数据可视化标杆

**亮点**:
- 交互式气候图表
- 30+ 年历史档案
- 多城市/多时段对比工具
- 季节趋势预报
- 风玫瑰图

**可借鉴**:
- **图表设计是最大亮点**——极简风格下把复杂气候数据做得直观易懂
- 对比功能的交互设计
- 适合参考预报数据的可视化方式

---

### 7. Weather.gov — 极简官方

**亮点**:
- 高分辨率多普勒雷达
- 与 FEMA 集成的恶劣天气警报
- 公共领域历史和气候数据集
- 气象学家预报讨论（Forecast Discussion）

**可借鉴**:
- 无广告的极简设计理念
- 信息架构（功能优先于装饰）

---

### 8. 彩云天气 — 国产设计标杆

**亮点**:
- 分钟级降水预报（国产 MinuteCast）
- 极简清新的设计风格
- 短时降水曲线图
- 透明卡片 + 动态背景

**可借鉴**:
- **国产天气 App 中设计最好的之一**
- 分钟级降水曲线的展示方式
- 透明卡片 + 动态天气背景的设计模式
- 简洁的信息层次

---

### 9. 墨迹天气 — 国内最大

**亮点**:
- 国内用户量最大的天气应用
- 生活指数丰富（穿衣、洗车、运动等）
- 短时降雨提醒
- 社区 UGC 内容

**可借鉴**:
- 国内用户的交互习惯
- 生活指数的产品设计思路

## 三、设计启发总结

结合本项目（4-6 小时笔试题，合理控制范围），从以上产品中提炼可落地的设计方向：

### 可落地的设计点

| 设计点 | 参考来源 | 落地难度 | 说明 |
|--------|---------|---------|------|
| 动态天气背景 | The Weather Channel / 彩云 | 中 | 根据天气状态切换背景色/渐变，提升沉浸感 |
| 透明卡片设计 | 彩云天气 | 低 | 毛玻璃/半透明卡片展示天气数据 |
| 体感温度 | AccuWeather | 低 | API 数据中已有或可简单计算 |
| 生活指数 | 墨迹 / AccuWeather | 中 | 根据温度/湿度推荐穿衣建议（可简单实现） |
| 预报图表 | WeatherSpark | 中 | 用简单折线图展示温度趋势 |
| 平滑过渡动画 | Windy | 低 | 天气状态切换时的 CSS 过渡 |

### 刻意不做的（控制范围）

| 不做 | 原因 |
|------|------|
| 地图可视化 | 4-6小时预算无法做好，不如不做 |
| 3D 地球 | 过度工程，与题目核心需求无关 |
| 雷达动画 | 需要额外数据源，超出范围 |
| 视频/社区内容 | 与核心需求无关 |
| 分钟级降水 | API 不一定支持，且属于增值功能 |
